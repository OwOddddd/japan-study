一條河從山到海

  1. 山地：高、陡、離海近 → 河短流急，帶下大量土砂（信濃川全長約 367 km，日本最長）
  2. 山口：流速降 → 放下礫石 → 扇狀地（果樹、旱田）
  3. 中下游：洪水漫出河道 → 沖積平原（水田、大城市）
  4. 河口：泥放在海邊 → 三角洲（港口、工業、都市）

台地與低地

關東平原的台地約占一半以上，武藏野台地不淹水、缺水，早期是旱田與雜木林；低地沿河發展，是水田與下町。
